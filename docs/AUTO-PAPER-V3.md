# 상위 계획 후 하위 진입 확인 — v3

강의의 상위 구역 → 하위 정제 흐름을 근거로 하되, 모든 강의 장면이나 예외를 재현했다고 주장하지 않는다. 기존 장면 기록은 6-6 19:23, 6-8 11:10/12:46이다. 사용자가 승인한 방향은 상위 구조로 손절·목표를 먼저 정하고 작은 봉으로 진입을 정밀화하는 것이다.

## 새 실험 규칙

H4 구역 접촉 → M15 전환 구역 확정 시 M15 바깥 손절과 H4 약한 극점 목표를 저장 → M15 재접촉 → 선택한 M1 또는 원본 M5 전환·정제 구역 재접촉. 상위 계획 시각은 하위 신호보다 앞서야 한다. H1 PP, 구역 A/B등급, 수수료·슬리피지 차감 순 2R, 현금 및 위험 한도를 추가 확인한다.

손절 완충 0.1%, 위험 0.5%, 최소 순 2R, M15 손절 선택, 등급 공식과 30분 진입 만료는 강의 고정 공식이 아닌 검증 설정이다. 손절 폭이 커지면 수량이 줄어든다. 손익비가 부족하면 목표를 늘리거나 손절을 줄이지 않고 대기한다. M1/M5는 진입 전에 선택하며 사후에 유리한 신호로 바꾸지 않는다. M1 원본은 양쪽 모델에서 체결 장벽 확인에도 필요하다.

고정 1R 절반 익절은 제거한다. 최초 손절·H4 목표·H4 구조 무효화·사용자 청산 요청으로 종료한다. 보유 후 작은 M1/M5 반전만으로 청산하지 않는다. 손절을 넓히거나 본전으로 옮기지 않는다. 자동 추적 손절 및 목표 너머 잔여 보유는 구현하지 않았으며 강의 규칙으로 표시하지 않는다.

## 버전과 검증

v1/v2 계좌·포지션·기록은 변경하지 않는다. 같은 종목도 모델과 진입 시간대별 별도 실험 계좌를 생성한다. 기존 실험은 필요하면 신규 진입을 중지하고, 새 v3를 시작한다. 각 실험은 별도 초기 자본과 통계를 가진다. 계정당 6개 제한은 유지한다.

자동 엔진 백테스트도 같은 advanceAuto와 새 기본 버전을 사용한다. 대시보드 후보는 동일한 상위 손절 계산을 사용하지만 과거 접촉을 재구성한 참고값이다. 실제 실험의 저장된 상위 계획이 체결 기준이며 차트 후보와 같다고 보장하지 않는다. 단일 시간대 구조 분석은 탐색용이다.

회귀 검증: 양방향 상위 손절·목표 고정, 수량 감소와 위험 한도, 1R에서 보유 유지, 하위 손절 통과 후 보유, 상위 손절 청산, 계획 누락·사후 계획 거부, 원본 M5 요구, 기존 v2 부분청산 유지. 수익성 개선은 확인되지 않았으며 과거/실시간 비교가 필요하다.
