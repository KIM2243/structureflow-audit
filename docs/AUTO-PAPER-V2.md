# 자동 모의투자 v2

프로필: `PP-H4-M15-M1-long-short-partial-v2`.

## 강의 근거와 구현 가정

강의 6-6(19:23)의 H4/M15/M1 흐름, 6-8(11:10, 12:46)의 상위 공급 구역·M1 정제, 6-10의 방향에 상대적인 PP/PC 구분을 참고했다. 실제 화면의 주요 구간을 검토한 기록에 근거하며 강의 전체의 모든 예외를 재현했다고 주장하지 않는다.

롱은 H4 상승의 할인 수요 구역, 숏은 하락의 프리미엄 공급 구역에서 출발한다. 실제 관측 접촉 이후 M15 CHoCH 또는 후속 BOS를 기다리고, M15 구역의 재접촉 이후 M1 전환·정제 구역 재접촉을 기다린다. M15는 H4 안, M1은 M15 안에 포함되어야 한다. H1 내부 구조가 진입 방향에 동행해야 하는 보수적인 PP 실험이다. 스윕 단독 진입·CP 반전은 추가하지 않았다.

구역의 꼬리–몸통 경계, 등급 배점, 손절 0.1% 완충, 위험 0.5%, 부분청산 비율과 시간 제한은 **실험 설정**이며 강의의 고정 공식이 아니다.

## 구역 등급

확정 구조 돌파 1점, 상위 범위의 유리한 위치 1점, 구역 폭의 1.5배 이상 종가 이탈 1점, 확정 후 재접촉 없음 1점, 재접촉 1회 이하 1점. 하위 정제 구역은 상위 구역 포함 1점을 더한다. 연속해서 구역과 겹치는 봉들은 한 번의 접촉으로 센다. 이탈 강도는 구역 확정 시점의 최근 3개 완료 봉만 사용한다.

A는 4점 이상, B는 3점, C는 2점 이하. 자동 진입은 H4/M15/M1 모두 A/B만 허용한다. 등급과 근거는 관측된 완료 봉으로 갱신하며 승률을 뜻하지 않는다. 차트의 등급 버튼은 해당 시간대의 현재 확정 구역을 그린다. 자동 패널은 실제로 추적 중인 3단계 구역과 각각의 근거를 보여준다.

## 부분청산·숏 회계

최초 수량의 절반(정수 내림)을 수수료·슬리피지 차감 후 1R에 청산한다. 1주는 부분청산을 생략한다. 잔여 수량은 고정 손절과 H4 약한 고점(롱)/저점(숏) 목표로 관리한다. 손절을 본전으로 옮기지 않는다. 부분청산을 반영한 가중 순 목표 R이 2 이상일 때만 진입하므로 절반 청산이면 최종 목표는 대략 순 3R 이상이 필요하다.

부분청산 시 진입 수수료를 수량 비례로 배분한다. 완료 거래 수·승률·평균 R은 잔여분까지 전부 청산한 뒤 한 번만 집계한다. 실현손익에는 이미 실행한 부분청산이 포함된다. 매수/매도와 진입/부분청산/청산을 구분해서 저장하고 CSV로 내보낸다.

숏도 진입 명목금액 전액을 현금에서 예약한다. 청산 시 예약금과 방향을 반영한 손익을 반환한다. 차입 매도 대금을 재투자하지 않으며 실계좌 주문은 전송하지 않는다. 대차 가능 여부·대차료·세금·호가 대기열·실제 부분체결은 반영하지 않는다. 같은 완료 봉에 손절과 부분청산 또는 목표가 함께 닿으면 손절 우선, 갭 손절은 더 불리한 시가로 계산한다.

## 1분봉과 운영 상태

메인 차트와 자동 실험은 원본 1분봉을 요청한다. 5분봉을 잘라 만들지 않는다. Yahoo 보조 차트도 제공처의 1분봉만 사용하지만 자동 체결은 키움 원본만 허용한다. 데이터가 없거나 지연되면 대기한다. 메인 화면은 보이는 동안 60초마다 차트를 갱신하며 선택한 시간대를 유지한다. 5분봉은 보조 시간대로 계속 제공한다.

차트의 진입 후보는 완료 봉으로 재구성한 검토 결과다. 자동 체결은 실험 시작 후 실제 관측한 접촉 순서로 따로 검증하므로 과거 후보를 소급 체결하지 않는다. 상단 단일 시간대 분석의 참고 가격과 실제 자동 포지션의 손절·목표를 구분한다.

기존 v1 계좌는 기존 롱·전량청산 규칙을 유지한다. 새로운 실험은 v2를 사용하며 버전별 결과를 섞지 않는다. 기존 계좌의 결과를 자동으로 초기화하지 않는다.

웹 기능의 배포와 Oracle 백그라운드 실행 완료는 별개다. 원본 M1을 제공하는 브리지와 runner의 연결·체결 로그를 확인하기 전에는 24시간 자동 실행 또는 이론의 수익성이 검증됐다고 보고하지 않는다. 이번 변경은 서버 재부팅을 요구하지 않는다.
